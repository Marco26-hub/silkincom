# Brief Originale Cliente

## Obiettivo

Sostituire `silkincom.com` (attualmente Wix) con e-commerce premium custom.

## Brand

- **Nome**: SILKinCOM
- **Settore**: Accessori in seta, cashmere, lana, lino, cotone — Made in Como
- **Posizionamento**: Boutique luxury italiana, tradizione tessile comasca
- **Reference estetici**: Loro Piana, Brunello Cucinelli, Hermès, Falconeri

## Stack tecnico obbligatorio

- Next.js + React + TypeScript + Tailwind + shadcn/ui + Framer Motion
- Supabase (PostgreSQL + Auth + Storage + RLS)
- Stripe (Payment Intents + Webhooks)
- Vercel (deploy)
- Resend / Brevo (email)
- GA4 + GTM + Meta Pixel
- Cookie GDPR consent-first

## Vincoli

- **NO** WooCommerce, NO Shopify
- TypeScript-first
- Server-side validation per pagamenti
- Mai chiavi private nel client
- RLS Supabase obbligatoria

## Output richiesto

6 fasi:

1. Strategia e architettura
2. Design system e UX
3. Database e backend
4. Frontend pubblico
5. Admin dashboard
6. Test, SEO, GDPR, Deploy

Ogni fase include sezione **AVVOCATO DEL DIAVOLO** con rischi, errori probabili, breaking points, priorità.

## Vincoli legali

- **NON inventare** dati aziendali (P.IVA, ragione sociale, sede)
- Pagine legali → PLACEHOLDER da redigere con consulente legale GDPR
- Affermazioni "Made in Como/Italy" devono essere documentabili
